### **1. 简介**

#### **1.1 产品背景**
随着智能手机摄像头能力的飞速发展，用户可以轻松录制 4K 甚至 8K 的高清视频。这些视频文件体积巨大，不仅迅速占满手机宝贵的存储空间，也给分享带来了极大的不便——大部分社交应用和电子邮件服务都对附件大小设有严格限制。

#### **1.2 产品愿景**
"视频瘦身器"旨在成为一款极致简洁、功能强大的移动端视频压缩工具。我们致力于通过智能的压缩算法和友好的用户界面，让每一位用户都能轻松、快速地缩小视频体积，从而解决存储焦虑和分享困难的问题。

#### **1.3 目标用户**
*   **存储空间敏感者:** 手机容量经常告急，希望释放空间的用户。
*   **社交分享达人:** 频繁通过微信、Discord、Telegram 等平台分享视频的用户。
*   **手机摄影爱好者:** 拍摄大量高质量视频素材，需要进行初步处理的用户。

#### **1.4 商业模式**
采用 **免费 + Pro版一次性买断** 模式：
- **免费版**：核心功能完整可用，批量压缩限制最多5个视频
- **Pro版**：一次性购买，解锁无限批量压缩

#### **2.2 非功能性需求**
*   **性能:** UI 响应流畅，列表滚动无卡顿。视频元数据加载快速。压缩算法应尽可能高效利用设备性能。
*   **易用性:** 界面设计遵循"Don't make me think"原则，核心流程（选择-配置-压缩）一气呵成。
*   **隐私:** 所有视频处理均在用户设备本地完成，绝不上传任何用户文件，确保用户数据隐私与安全。
*   **兼容性:** 稳定运行于 iOS (13.0+) 系统版本。
*   **健壮性:** 对各种异常情况（如权限被拒、文件损坏、压缩失败等）有优雅的错误处理和提示。

**5. 视频状态说明**
- **等待下载**: iCloud视频需要先下载
- **下载中**: 正在从iCloud下载
- **等待中**: 排队等待压缩
- **压缩中**: 正在压缩，显示进度条和预估剩余时间
- **已完成**: 压缩完成，可保存到相册
- **已保存**: 已保存到相册并删除原视频
- **已取消**: 用户取消，可重新压缩
- **失败**: 压缩失败，显示错误信息，可重试

### **4. 技术考虑**

*   **核心技术:** `ffmpeg_kit_flutter`。这是实现所有视频处理功能（压缩、转码、元数据提取）的基础。
*   **元数据提取:** 使用 FFprobe 工具来分析视频文件，获取分辨率、帧率、色彩空间等详细信息。
*   **高级媒体库:** 使用 `photo_manager` 库来高效加载和管理系统相册中的视频。
*   **权限处理:** 使用 `permission_handler` 库来优雅地请求和管理权限。
*   **状态管理:** 使用 `flutter_bloc` (Cubit) 来管理复杂的 UI 状态，如筛选条件、选择列表和压缩进度。
*   **内购支付:** 使用 `in_app_purchase` 或 `purchases_flutter` (RevenueCat) 实现iOS应用内购买。

*   **暂停/恢复能力:** FFmpeg 不支持真正的"暂停/恢复"编码流程。实现策略：
    - 正在压缩的视频仅支持"取消"，取消将终止当前进度；
    - 恢复等价于"重试"，会从头开始该视频的压缩；
    - 队列由状态管理（Cubit）维护，严格顺序处理（一个一个压缩）；
    - 提供单视频的明确状态与操作反馈（等待下载/等待中/下载中/压缩中/已完成/已保存/已取消/失败）。
